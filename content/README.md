# Content Directory Guide for AI

This `content` directory is dedicated to storing articles and insights generated by AI, organized by language for optimized usage.

## Directory Structure
The subfolders under `content` represent different language codes, ensuring clarity and organization. Here is the structure:
```
/content
├── insights
│   ├── ar  (Arabic)
│   ├── de  (German)
│   ├── en  (English)
│   ├── es  (Spanish)
│   ├── fr  (French)
│   ├── it  (Italian)
│   ├── ja  (Japanese)
│   ├── ko  (Korean)
│   ├── pt  (Portuguese)
│   ├── ru  (Russian)
│   └── zh  (Chinese)
```
Language-specific articles should be placed in their respective folders.

## AI Content Generation Guidelines
1. **Purpose:**
   - Articles should focus on SEO optimization for the document translation service.
   - Highlight key features: multi-language support, layout preservation, glossary management, and structural consistency.

2. **File Naming Convention:**
   - Use descriptive filenames that are intuitive and align with the content's purpose (e.g., `business-use-case.md`, `document-layout-guide.md`).
   - Avoid strict naming formats; flexibility is encouraged.

3. **Placement:**
   - Place the generated articles in the corresponding language folder under `/content/insights/`.

4. **Content Structure:**
   - **Introduction:** Provide an overview tailored to the target audience of that language.
   - **Features:** Discuss the service's advantages in language-specific contexts.
   - **SEO Keywords:** Integrate language-relevant long-tail keywords naturally.

## Workflow for AI
- Identify the target language's folder.
- Generate content according to the guidelines.
- Save the file in the correct location with the specified naming convention.

### Notes for AI
- Ensure consistency in naming and placement to avoid mismanagement.
- If a new language is added, create a corresponding folder within `/content/insights/` and adhere to the structure.

---
By following these guidelines, AI can consistently organize and generate content suitable for multilingual insights and SEO campaigns.
