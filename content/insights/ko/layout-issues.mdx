온라인 번역 도구로 Word 또는 PDF 문서를 번역해 본 적이 있다면, **번역 후 레이아웃이 완전히 깨지는** 문제를 겪어 보셨을 겁니다.

## 흔한 레이아웃 문제

번역 후 다음과 같은 문제가 자주 발생합니다:

### 1. 표 틀어짐
정렬된 표가 열 너비 불일치, 텍스트 넘침, 행 높이 혼란으로 망가집니다.

### 2. 글꼴 변경
신중히 고른 글꼴이 시스템 기본 글꼴로 바뀌어 전문성이 떨어집니다.

### 3. 페이지 레이아웃 혼란
- 머리글/바닥글이 사라짐
- 단(컬럼) 레이아웃이 깨짐
- 이미지 위치가 이동됨

### 4. 서식 손실
- 굵게/기울임이 사라짐
- 글머리표/번호 매기기 오류
- 들여쓰기와 정렬 문제

## 왜 이런 일이 생길까요?

원인은 기존 번역 도구의 작업 방식에 있습니다:

1. **텍스트만 추출**: 서식 정보를 무시
2. **길이 변화**: 번역문 길이가 원문과 다름
3. **문자 폭 차이**: 언어별로 차지하는 공간이 다름
4. **되돌려 넣기 어려움**: 원 위치에 맞게 재삽입 불가
