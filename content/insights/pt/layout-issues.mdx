Se você já usou uma ferramenta online para traduzir documentos Word ou PDF, com certeza já viu isso: o **layout do documento traduzido fica totalmente bagunçado**.

## Problemas de layout comuns

Após a tradução, os problemas mais comuns são:

### 1. Tabelas desalinhadas
Tabelas organizadas passam a ter larguras de coluna erradas, texto estourando e alturas de linha inconsistentes.

### 2. Mudança de fonte
A fonte escolhida com cuidado é substituída pela fonte do sistema, deixando o documento pouco profissional.

### 3. Layout de página caótico
- Cabeçalhos e rodapés desaparecem
- O layout em colunas se quebra
- Imagens mudam de posição

### 4. Perda de formatação
- Negrito e itálico desaparecem
- Erros em marcadores e numeração
- Problemas de recuo e alinhamento

## Por que isso acontece?

A raiz do problema está no funcionamento das ferramentas tradicionais:

1. **Extração de texto puro**: só o texto é extraído, sem informações de formato
2. **Mudança de comprimento**: o texto traduzido tem tamanho diferente do original
3. **Codificação de caracteres**: línguas diferentes ocupam espaços diferentes
4. **Reinserção difícil**: a tradução não se ajusta à posição original
